# EasySampler

(旧名 MADDAW。公開先: https://easysampler.pages.dev/ — Cloudflare Pages、master への push で自動更新)

素材を入れたら、DAW に渡せる音源になる。音MADの「シンセ化」(素材を切り出し、音程を平らにして1音に伸ばし、サンプラー用の WAV にする)を、ブラウザの1画面で行うツール(開発中)。
Windows・Mac・iPhone・iPad の Safari / Chrome で動く。生成AIは使わず、素材は端末の外に出ない。
設計は [docs/design.md](docs/design.md)(v2.0)。v1.2 までの「DAW」構想は [docs/design-v1.2.md](docs/design-v1.2.md) に残してある。

**プリセット**(2026-10-28 に 4 つへ厳選): シンセ化(平坦)・短い素材・移調のみ・減衰(伸ばしながら消える・ピアノ風)。ほかの音(ビブラート入りのリード、引き延ばし、ウェーブテーブル、ケロケロ、人力など)は、シンセ化から伸ばし方・ビブラート・平坦化・音程の整え方を変えて作る。ドラムはドラムキット(13.2)。**語尾は 2026-10-28 に撤廃**: 伸ばす音は離すとリリースで消え、伸ばさない音は録音の終わりまで鳴る(下の語尾に関する記述は当時のもの)。

## 現在: Phase 3 まで(Signalsmith モードを除く)

1. 素材(声や効果音のファイル)を開くと、ピッチカーブ・ピッチマーク・セント単位の基準ピッチ・シンセ化マーカー(頭部 / 持続区間 / 語尾)を自動で解析する。60 秒を超える素材(動画の音声など)は、全体の波形から使う範囲を選んでから解析する。あとから「別の範囲を選ぶ」で選び直せる。
2. 波形の上で範囲とマーカーを直し、目標の音名と長さ(拍数 + BPM、または秒)を決める。長い素材は「区間を追加」で何か所でも切り出せる。画面の鍵盤や PC のキーボードで試し弾きできる。
3. 形式を選んで「共有 / 保存」する。
   - **単音 WAV**: どのサンプラーでも。音名と出典メモが WAV に入る。
   - **ループ WAV**: ループ範囲を `smpl` チャンクに埋め込み、継ぎ目をクロスフェードで消したもの。
   - **マルチサンプル音源(zip)**: ±1 オクターブを 3 半音おきに、それぞれの高さで PSOLA で作った WAV と、`.sfz`(sforzando など)・`.dspreset`(Decent Sampler。iPhone / iPad でも無料)の定義。読み込む先に Decent Sampler を選ぶと zip は `.dslibrary` の名前で出て、iPhone の「ファイル」からタップするだけで取り込める。
   - **Vital 用ウェーブテーブル**: 持続区間の 1 周期ずつを 2048 サンプルに揃えて並べた WAV。Vital の OSC にドラッグするか「Import Wavetable」で読む(フレームの切れ目を `clm ` チャンクで伝える)。
   - 区間が複数あれば「すべての区間をまとめて保存」で 1 つの zip に(設定 JSON 同梱)。
   - **ドラム / 効果音の一括処理**: ファイルを複数まとめて開くと素材リストになる。1 つずつ開いて調整でき、「キット音源にする」で各ファイルを 1 鍵ずつ並べた SFZ + Decent Sampler の zip、「すべて単音 WAV で保存」で WAV の zip になる。調整していない素材はワンショット(録音のまま)。
4. VocalShifter の TIME のように編集できる。波形上を横にドラッグして範囲を選び「選択した部分を削除」(いらない部分をカット。削除した範囲は詰めて表示され、✂ の点線が継ぎ目)、「選択した部分だけ残す」(トリミング)。頭部・持続区間・語尾それぞれの速度(倍率)も変えられる。エディタ最下段の「書き出し後」レーンに、出力の時間配分とビブラートの波形が出る。Ctrl + ホイールやピンチで拡大、ホイールや 2 本指で横スクロール。再生は 1 つのトランスポート([元の音 | 書き出し後] の切り替え + ▶ / ■。スペースキーも同じ、■ は再生を始めた位置に戻る)。波形の上の目盛りを 1 回押すと再生位置、2 回押すとそこから再生、引くとなぞれる(「書き出し後」レーンも同じ)。元に戻す / やり直す(Ctrl + Z / Ctrl + Y)。
5. 判定が外れていたら直せる。波形上を横にドラッグして範囲を選び「オクターブ上 / 下」「無声に / 有声に」。点線(判定した音程)は上下にドラッグで半音ずつ、Alt でセント単位、ダブルクリックで最寄りの半音。
6. 持続区間の伸ばし方: 「周期プール(自然)」のほか、**「引き延ばし」**(持続区間全体を「長さ」に収まるよう遅く再生。VocalShifter の TIME のように声の変化を残したまま伸び、長さを超えて押し続けると区間の終わりから周期プールで続く)、「ループ」、「ウェーブテーブル(1〜数周期の繰り返し、無機質)」がある。で一発。
7. 設定(区間・マーカー・つまみ・音名・手直し・削除・長さの倍率)は素材ごとに端末に残り、同じ素材を開き直すと戻る。「書き出し」の「設定ファイル」で JSON として保存・読み込みもできる(出典メモもそこ)。鍵盤は「画面下に固定」で、下の設定を触りながら試し弾きできる(PC では既定でオン)。
8. **MIDI を開く**(打ち込みの中): MIDI ファイル(.mid)を開くかページにドロップすると、パートごとにトラックができる(ドラムのチャンネルはドラムトラックになり、鳴っている打楽器ごとに行ができる)。いちばん音符の多いメロディは編集中の区間で、ほかは簡易シンセ(伴奏)・簡易ドラムで鳴るので、開いてすぐ曲全体が聞ける。トラックの区間を選び直せば素材で鳴る。テンポは曲のものになる(途中の変更は最初のテンポにそろえる)。まったく同じ音符のトラックは 1 本にまとめる。2026-10-28 に「曲で試す」パネルをこれに統合した。
8a. **音程の整え方**: 「判定した 1 音に寄せる」(既定)のほか、**「音階の最寄りの音に、場所ごとに寄せる」**(キーと音階を選ぶ。素材の中の音の変化を音階に貼り付ける。VocalShifter のクオンタイズ / 自動補正。平坦化 100%・揺らぎなし・リチューン即座でケロケロ)。ビブラートには立ち上がり・離したあとの消え方・位相・トレモロ、素材自身の揺れをならす平滑化がある。判定の手直しには「±N¢ ずらす」「音名に」、細かい設定に「判定の探索範囲」。
8d. **移調のみ**: プリセット「移調のみ(シンセ化せず全体を上げ下げ)」。平坦化も伸ばしもせず、区間全体を録音のまま 1 回通して、押した鍵のぶんだけ上げ下げする(長さと声色は保つ)。早回しの質感が欲しければ「短い素材(速度連動)」。
8e. **短い素材**: 「ファッ！？」のような、伸ばさず音程だけ付ける素材向けにプリセット「短い素材(長さ保持・そのまま音程だけ)」(PSOLA で長さと抑揚を保ち、子音も追従)(早回し質感にするなら「ピッチの変え方」を「速度連動」に)。伸ばせる安定した部分が 0.2 秒未満(または全体が 0.5 秒未満)の素材は、読み込み時に自動でこのプリセットになり、その旨を表示する。
8d. Melodyne / Auto-Tune 由来: **音程を寄せる速さ(リチューン)**(0 = 即座 = ケロケロ、30 ms 前後で自然、長いとゆっくりした狂いだけ直る)、ビブラートの中に **素材のゆっくりした揺れ(ドリフト)／速い揺れ(ビブラート)を残す**(−100〜100%、マイナスで反転。Melodyne のピッチドリフト / モジュレーション)、**子音・息の音量**(−60 dB で消す。Sibilant Balance)、細かい設定の **声質追従** は量(0〜100%)に。
8c. **持続部の音量を揃える**(既定 100%): 素材の持続区間が減衰していても、伸ばした音の音量が一定になる(各周期を持続区間の中央値へ。増幅は 4 倍まで)。頭部と語尾はそのまま。
8b. **音程なし(無声)の部分も移調に合わせて変える**: 子音・息・ノイズは通常、移調しても元のまま。オンにすると、その部分のグレインを移調分だけ速く / 遅く読み(長さは保つ)、音名に応じて細く / 太くなる。音程そのものを付けるなら、選択して「有声に」。
8f. **打ち込み**(DAW 化、docs/design.md 13 章): 複数の素材を 1 つのプロジェクトに持ち(「＋ 素材を追加」、上の「素材」で編集する素材を切り替え)、トラックごとに素材の区間を 1 つ選んで鳴らす。トラックには音量・パン・ミュート・ソロとエフェクト(下の「エフェクト」は選んでいるトラックかマスターのもの)。**ドラムトラック**は、割り当てた区間の数だけピアノロールに行ができ、各行は区間を録音どおりの高さで鳴らす(区間の設定から 1 回だけ作ったワンショットを再生するので軽い)。ピアノロールは選んでいるトラックを編集する: 置く・消す・動かす・長さ・吸着(1 拍〜1/8 拍、3 連)・範囲選択・コピー / 貼り付け / 複製・移調・取り消しと、目盛りのドラッグでループ範囲。ピアノロール下の欄を「音量の線」「パンの線」「マスター音量の線」にすると、曲の中で音量やパンを動かす線(オートメーション)を引ける。目盛りで選んだ範囲は、全トラックまとめて空白の挿入・削除・複製ができる。途中のテンポ変更も置ける(MIDI のテンポ変更も読み書きする)。**音声トラック**には素材の録音をそのまま並べられる(クリップの途中からの再生・スライス対応)。鍵盤(画面・PC・MIDI キーボード)でのリアルタイム録音(カウント・メトロノーム付き)と、マイクで録った音を素材にすることもできる。MIDI ファイルを開くと、パートごとのトラックになる(上の 8)。プロジェクト(素材の音声と設定を含む)はブラウザ内に自動保存され、次に開いたとき戻る。単音の書き出しと試し弾きはエフェクトなし(エフェクトはトラックのもの)。**曲の書き出し**: 「曲を WAV で」(全トラックのミックス + マスター。音割れしそうなら全体を下げる)、「トラック別の WAV(zip)」(各トラックのエフェクト込み、マスターなし)、「MIDI(.mid)」(音符だけ。ドラムの行は 10ch の GM ドラムの鍵に)。再生と同じミキサーをオフラインで回すので、聞こえたとおりに書き出される。
9. **エフェクト**: 区間ごとに、フェード(入り = アタック、終わり = 素材が尽きる手前と音を離したあと。「書き出し後」レーンに音量の水位として出る)・トランジェント(アタック / サステイン)・コンプレッサー・EQ(低域カット・低域・中域ベル・高域・高域カット)・サチュレーション(真空管風)・エア(高域の抜け)・フィルター(拍に合わせた LFO)・ビットクラッシャー・コーラス・ディレイ(拍に同期、ピンポン)・リバーブ・ステレオ幅(ミッド / サイド)・オートパン・リミッターを、この順にかけられる。試し弾き・打ち込み・書き出す WAV のすべてに同じものが入る(Vital 用ウェーブテーブルを除く)。コーラス・リバーブ・ピンポンディレイ・オートパンを使うと、モノラルの素材もステレオで書き出す。

### 聴取レポート(耳の代わりの測定)
```bash
npm run listen -- --material demo --preset synth --note D4 --hold 1
npm run listen -- --material clip.wav --set sustainMode=stretch --set wobble.vibratoCents=25 --out reports/x
npm run listen -- --material demo --against reports/x   # 前回との差
```
書き出しと同じ経路で 1 音を描画し、`reports/<時刻>/` に WAV・スペクトログラム(ピッチ線・波形・音量付き)・`report.md`・`metrics.json` を書く。測るのは音程(ずれ・ゆらぎ・ビブラートの実測)、音量(立ち上がり・ふらつき・フェード)、音色(重心・2–5 kHz・8 kHz 以上・ノイズ感)、不快さの指標(クリック・クリッピング・20–200 Hz の振幅変調 = ざらつき・途切れ・ループの継ぎ目)。しきい値を超えたものは「気になる点」に並ぶ。`--set` は InstrumentParams のドット区切り(`tune.mode=scale`, `fx.chorus.on=true`)。

```bash
npm install
npm run dev       # http://localhost:5173
npm test          # 解析・エンジン・書き出しのテスト (Vitest)
npm run build     # dist/ に静的ファイル(Cloudflare 向け。_headers 付き)
```

### iPhone / iPad で試す
AudioWorklet は安全な接続(HTTPS)でしか動かないため、LAN 内では HTTPS で配信する。

```bash
npm run dev:lan
```

表示された `https://192.168.x.x:5173` を Safari で開く。証明書の警告が出るので、許可して進める。
URL に `?bench` を付けると、24 ボイスを鳴らしたときの処理負荷を測るボタンが出る。
