## 各ツールがしていること

### iZotope Ozone(Master Assistant)

1. 曲を数秒聞いて、**目標の周波数カーブ**を作る。ジャンルごとのカーブとの近さを点数にして混ぜる(例: ポップ 60%・ロック 30%・カントリー 10%)。参照曲を渡すと、そのカーブを目標にする。
2. **EQ** を、入力と目標カーブの差から決める(両端のシェルフは必ず使う)。
3. **Stabilizer**: 目標の音域バランスへ動的に寄せる(shape)か、目標の上限を超えた共鳴だけを削る(cut)。
4. **Impact**: 帯域ごとの細かいダイナミクス(マイクロダイナミクス)。
5. **Imager**: 帯域ごとの左右の広がり。
6. **Maximizer**: 目標のラウドネスと出力先から、天井としきい値を決める。

### iZotope Neutron(ミックス)

- **Balance**: トラックを種類でまとめて音量を決める。
- **Unmask**: 「下げる側」のトラックに入れ、「聞かせたい側」をサイドチェーンに入れる。2 つがぶつかる帯域を見つけ、**ぶつかっている間だけ**その帯域を下げる(固定の EQ ではない)。感度・戻り時間・効かせる帯域・量のつまみ。

### iZotope の記事にあるマスタリングチェーンの順番

リミッターでまず音量を決める → 補正の EQ → 補正のダイナミクス(マルチバンド。例は 130 Hz 以下と 3 kHz 以上)→ 味付けのコンプ → 味付けの EQ → リミッター。補正は味付けより先、補正では EQ(線形)がコンプ(非線形)より先が「10 回中 9 回」。

### sonible(smart:comp / smart:EQ)

- 入力をフーリエ変換で細かい周波数に分け、それを帯域にまとめて検出・処理する。帯域数は用途しだい: smart:reverb は約 30、smart:EQ 3 は 100 以上、smart:comp 2 は 2000 以上。100〜500 Hz は細かさが要る。
- smart:comp は、固定のしきい値と比べるのではなくスペクトルを見て、必要な帯域だけ下げる(だから透明)。量 0 なら普通のコンプ。

### Newfangled Audio(クリップとリミットの使い分け)

- クリップは瞬時(先読みなし)で、**キックやスネアなど速い立ち上がり**に向く。歪みが聞こえやすいのは、持続音や音程のある音。
- リミッターは時間をかけて働く(先読み・アタック・リリース)。最終の音量とトゥルーピークの安全に向く。「立ち上がりを抑える係」にしない。
- 順番: EQ → クリッパー → リミッター。
- 量の目安: クリップは **0.5〜2 dB まで**、リミッターの抑えは **平均 1〜3 dB**、トゥルーピーク −1.0 dBTP。リミッターが 3〜4 dB 以上働いていたらクリップを足す、5 dB 以上なら分担する。大きく詰めるなら、**ドラムの素材の段階でクリップする**。

### Matchering(オープンソースの参照マスタリング。コードを読んだ)

1. 左右を中央(M)と横(S)に分ける。最大 15 秒ごとに切り、**大きい区間だけ**(区間の RMS が「区間 RMS の RMS」以上)を分析に使う。
2. 参照曲と RMS が合うゲインを 1 つかける。
3. **周波数合わせ**: 4096 点の FFT の平均(振幅)で参照 ÷ 対象を取り、対数周波数の上で滑らかにして(LOWESS、幅 3.75%)、4096 タップの直線位相 FIR にする。M と S に別々の FIR。
4. RMS の補正を 4 回(±1 でクリップしたものを測り直して合わせる)。
5. リミッター(Hyrax): 先読み約 1 ms の最大値フィルター、ホールド 1 ms、戻りは 2 段。オーバーサンプリングなし、サンプルのピークで見る。

### 自動ミキシングの研究(未確認: 総説を読めなかった)

一般に知られている範囲では、トラックの聞こえの大きさをそろえる音量決め、周波数の高い音源ほど外へ振るパン、トラック同士のマスキングを減らす EQ、信号の特徴から決めるコンプ、が主な題材。出典は確かめていないので、ここからは候補を立てていない。

## EasySampler の今との対応

| 工程 | ツール側 | EasySampler(今) | 差 |
|---|---|---|---|
| 目標カーブ | ジャンルの混合、または参照曲 | 3 種類から手で選ぶ | 参照曲から作れない。自動で選ばない |
| 全体の EQ | 多バンド、または 4096 タップの FIR | ローカット + 3 バンド、差の半分まで | 細かいへこみ・山は直せない |
| 動的な音域の補正 | Stabilizer、smart:EQ | なし | — |
| トラック同士のぶつかり | Unmask(ぶつかる間だけ下げる) | 固定の −2〜−3 dB のディップ 1 か所 | 動的でない |
| 密度 | クリッパー → リミッター、素材の段でクリップ | マスターのピークを丸める(最大 5 dB 下から)→ リミッター | 丸めをマスターだけで負っている |
| 帯域ごとのダイナミクス | Impact、マルチバンド | なし | — |
| 広がり | 帯域ごと(Imager)、M と S で別の EQ | 全帯域一律のステレオ幅 | 高域だけ広げられない |
| 最終の音量 | 目標ラウドネスから決める | −15 / −14 / −11 LUFS、トゥルーピーク −1 dBTP | 同等 |
| 分析に使う区間 | 大きい区間だけ | −60 dBFS 未満だけ除く | 静かな場面が平均に入る |

## 実装してみた結果(2026-11-25、同日)

ユーザーの依頼で上から順に。数値はユーザーの曲のトラック別の書き出し(16 本)と、曲の書き出しでの実測。

| 候補 | 結果 |
|---|---|
| 1. ドラムのトラックでピークを丸める | **見送り(効果なし)。** ドラムを自分のピークの 2〜8 dB 下から丸めても、曲のピークと大きさの差は 13.3 dB のまま変わらなかった。ピークの上位 3 dB にいる瞬間の内訳は、ベース 2 が 36%、シンセベース・ドラム・ベース 1 が各 1 割前後で、**何本もの音がたまたま重なった所**がピークになっている。各トラック自身のピークは別の瞬間にあるので、内訳の上位 1〜3 本を 6 dB 下から丸めても 13.3 dB のまま。重なりでできるピークは、重なったあと(マスター)でしか丸められない。 |
| (並列コンプ) | **見送り(効果が小さい)。** 強く潰した音を同じ大きさで足して 13.3 → 12.9〜13.0 dB。アタック 20 ms では逆に 15.2 dB。 |
| 2. 高域だけ広げる | **実装。** ステレオ幅に「ここから上だけ」(`width.fromHz`)。「広がりを寄せる」は 400 Hz より上の横の成分(`sideUpDb`)を −6.5 dB へ、400 Hz から上だけ、最大 150%。自動ミックスだけの曲が −8.6 dB、手で 130% にした曲が −6.3 dB。 |
| 3. 参照曲から目標を作る | **実装。** 「参照曲を開く」で、その曲の 1/3 オクターブの形が「音域の目安」に入る(形だけをブラウザに保存)。寄せたあと、曲にいちばん近い目安が選んだものと違えば知らせる。「大きい区間だけで分析する」は入れていない(トラックの EQ の測定も同じ関数なので、全部の結果が動く)。 |
| 4. ぶつかる間だけ下げる EQ | **見送り。** メロディが鳴っているかどうかを音符から取ればキー自体は安く作れるが、(a) 役割をページから音声スレッドへ渡す経路を新しく作ることになり、(b) メロディを場面ごとに何本ものトラックで受け渡すこの曲では「メロディが鳴っていない間」がほとんどなく、固定のディップとほぼ同じ結果になる。効果は耳でしか確かめられない。 |
| 5. 全体の EQ のバンドを増やす | **実装。** EQ に 2 つめのピーク(`mid2…`)。マスター EQ の寄せは 2 つとも使い、2 つめは持ち上げを +3 dB まで(鳴らすトラックのない帯域を EQ で埋めない)。同じ曲で、目安との差の平均 2.25 → 1.77 dB、250 Hz のへこみ −9.1 → −6.5 dB(1 つのときは −9 dB のまま)。**訂正(design.md 49):** このへこみは曲の調(G)が作る 1/3 オクターブ 1 帯だけの谷で、今は帯を 1 オクターブずつ読んで寄せる。 |

密度について分かったこと: この曲でピークと大きさの差を縮められるのは、マスターでの丸めだけ。素材の段でのクリップが効くのは、ピークを 1 つの音(キックなど)が作っている曲。

## 実装の候補(勧める順)

### 1. ドラムのトラックでピークを丸める(小)

- 根拠: Newfangled の「クリップは 0.5〜2 dB まで」「大きく詰めるならドラムの素材の段で」。実測では、マスターの丸めは最大 5 dB 下からで、それでもピークと大きさの差は 14.0 → 13.2 dB(市販 3 曲は 6.8〜14.1)。目安の 2 dB を大きく超えて、ほかの音にも触れている。飛び出しているのはドラムの頭。
- 案: 「密度を上げる」を 2 段にする。先にドラムのトラックをそれだけで測って丸め、残りをマスターで 2 dB 以内。エフェクト `clip` はもうトラックにも使える。
- 危険: ドラムの音色が変わる(立ち上がりが丸くなる)。

### 2. 高域だけ広げる(小〜中)

- 根拠: 市販曲は高い音ほど広い(4〜8 kHz の横の成分 −3.5〜−10.7 dB、8〜16 kHz −2.3〜−11.9 dB)。AI ミックスは全帯域一律の 130% で、8〜16 kHz は −11.5 dB にとどまる。Ozone の Imager、Matchering の M/S 別 EQ が同じことをしている。
- 案: ステレオ幅に「この周波数から上だけ」を足す(横の成分にハイシェルフ)。「広がりを寄せる」を、帯域ごとの測定で決める。
- 危険: モノラルの素材が多い曲では、広げる横の成分がそもそもない。

### 3. 参照曲から目標を作る・目標を自動で選ぶ(小)

- 根拠: Ozone の参照モードとジャンルの混合、Matchering の全体。今は 3 種類を手で選ぶだけで、市販 3 曲でも目安から平均 2〜4 dB 外れていた(目安は 1 つの形にすぎない)。
- 案: (a) 参照曲の WAV を開くと、その 1/3 オクターブのカーブを目安にする(`bandSpectrum` と `fitBalance` はそのまま使える)。(b) 3 種類のうち曲にいちばん近いものを初期値にする。(c) 分析を「大きい区間だけ」にする(Matchering の選び方)。
- 危険: 参照曲と編成が違うと、ない帯域を持ち上げる(今回の 250 Hz のへこみのように、鳴らすトラックがない帯域は EQ で埋めない、という上限が要る)。

### 4. ぶつかっている間だけ下げる EQ(中)

- 根拠: Neutron の Unmask。今のディップは固定なので、メロディが鳴っていない間も伴奏が削れたまま。
- 案: トラックの EQ のディップを、メロディのトラックをキーにした動的な帯域にする。キーを渡す仕組み(サイドチェーンの `setKey`)はある。帯域ごとのキーにするには、キー側に帯域フィルターが要る。
- 危険: 計算が増える(iPhone)。効果は耳でしか確かめにくい。

### 5. 全体の EQ のバンドを増やす(中)

- 根拠: Matchering は 4096 タップ、Ozone も多バンド。今は 3 バンドなので、250 Hz だけのへこみのような形は直せない。
- 案: ピークを 2〜3 個に増やす(FIR ではなく双 2 次のまま)。
- 危険: 3 の「ない帯域を持ち上げない」上限と組でないと、害が出る。

## 見送るもの

- **マスターのコンプ / マルチバンドコンプ**: 実測で、コンプ(2:1〜3:1、アタック 3〜30 ms)はピークと大きさの差を広げた(14.0 → 14.1〜15.0 dB)。マルチバンドは、調べた範囲でも「控えめに」「音域バランスを壊しうる」とされる。
- **スペクトル処理(Stabilizer、smart:comp の 2000 帯域)**: FFT を音声スレッドで回すことになり、遅延と重さが大きい。書き出しのときだけにする手はあるが、再生と書き出しで音が変わる。
- **学習した AI モデル**: LANDR は中身が非公開で、まねる材料がない。学習データもない。上の候補は全部、測定と規則でできる。

## まだ確かめていないこと

- 並列コンプ・上向きコンプで密度が上がるか。小さい音を持ち上げてピークを変えないので、理屈ではピークと大きさの差が縮む。候補 1 の前に、実曲で測る価値がある(コンプに「混ぜる量」を足すだけで試せる)。
- 自動ミキシングの研究の中身(総説を読めていない)。
- どの候補も、耳での確認。
