## 0. v1.2 からの転換

| | v1.2(素材シンセ DAW) | v2.0 案(シンセ化ツール) |
|---|---|---|
| 作るもの | ブラウザで動く音MAD用 DAW。素材の解析からピアノロールでの打ち込み、ミックス、WAV 書き出しまでを1画面で行う | **シンセ化の工程だけ**を1画面で行い、**使っている DAW に渡せる音源ファイル**を書き出す。DAW は作らない |
| 解決する痛点 | 4つのソフトの往復、Windows 専用ソフト、サンプラーの欠点 | **シンセ化のために多くのアプリを立ち上げる面倒**(REAPER → VocalShifter LE → REAPER / Vital)、**iOS ではこの工程を行う手段がない**こと |
| 出力 | 曲の WAV | 単音化 WAV(VocalShifter の出力に相当)、マルチサンプル音源(SFZ など)、Vital 向け素材 |
| 完成までの距離 | ピアノロール、シーケンサー、ミキサー、保存、Undo…(Phase 2〜4) | Phase 1 の成果(解析・マーカー・素材シンセ・鍵盤)に**切り出しと書き出しを足せば使える** |

v1.2 で決めた中身のうち、**素材の解析(★2)、平坦化スライダー(★3)、シンセ化マーカーと素材シンセ(★4)、姿勢(AI を使わない、素材は端末の外に出さない)は、そのまま v2.0 の中核になる。** 捨てるのは「DAW としての部分」(ピアノロール、トラック、ミキサー、シーケンサー、ハモりボタン、曲のデータモデル)だけ。

## 1. コンセプト

**素材を入れたら、DAW に渡せる音源になる。** 切り出し、音程の判定と平均化、伸ばし、書き出しを、ブラウザの1画面で。Windows・Mac・iPhone・iPad で同じように動き、素材は端末の外に出ない。

### 売り

| | 売り | 解決する痛点 |
|---|---|---|
| **★1** | **シンセ化の往復をなくす。** REAPER での切り出しとフェード解除、VocalShifter LE での平均化・自動補正・TIME、WAV 書き出し、という手順を1画面に収める。REAPER はサンプラーに割り当てる段階で初めて開けばよい | 素材1つに3つのアプリを往復している |
| **★2** | **iOS で完結する。** iPhone・iPad の Safari で開き、できた WAV を共有シートから GarageBand・Koala・Logic・ファイルに渡す | VocalShifter も Vital も iOS にはない。iOS ユーザーはシンセ化の工程に入れない |
| **★3** | **音程をセント単位で自動判定し、スライダー1本で平坦化の度合いを決める**(v1.2 ★2・★3 を継承) | 素材の音程が分からない。平均化すると声が機械的になる |
| **★4** | **子音を守って母音だけ伸ばす**(v1.2 ★4 のシンセ化マーカーを継承)。伸ばす長さは BPM と拍数で指定できる | VocalShifter の TIME で制御点を手で打っている。伸ばした母音がうねる・ロボット声になる |
| **★5** | **渡す先に合わせた書き出し。** 単音 WAV のほか、音域ぶんの WAV を束ねたマルチサンプル音源(SFZ / Decent Sampler)、Vital 用のウェーブテーブル | サンプラーで基準音を手で合わせている。高音で素材が途中で切れる |

### 姿勢(v1.2 から継承)
- 生成 AI を使わない。学習もしない。素材は端末の外に出さない。
- 声のデータベースやプリセットを配布しない。素材ごとに出典メモを記録でき、書き出すファイル名やメモに残せる。

### やらないこと
- 曲を作ること全般(ピアノロール、トラック、ミキサー、シーケンサー、プロジェクト保存)。
- 録音、プラグイン、映像、AI による声の生成や変換、素材を使わない普通のシンセ音。
- BGM の除去(参考記事の「手順0」)。Ultimate Vocal Remover などに任せ、「BGM 入りの素材は先に除去を」と案内する。

## 2. 参考手法と、サイトでの対応

参考記事の手順を、そのままサイトの機能に写す。

| 参考記事の手順 | 使うソフト | サイトでの対応 |
|---|---|---|
| 素材を読み込み、スナップを外し、S キーで始点・終点を分割する | REAPER | 波形上の**範囲ハンドル**で切り出す。スナップなし。立ち上がり(onset)に軽く吸着する補助だけ付ける |
| 切り出した部分のフェードを外す | REAPER | **既定でフェードなし**。クリック音を防ぐための 1〜2ms のゼロクロス処理だけ行う(オプションで切れる) |
| WAV にレンダリングする | REAPER | 不要(往復がなくなる) |
| テンポを課題曲に合わせる(例 165) | VocalShifter LE | **BPM 欄**。伸ばす長さを拍数で指定するために使う |
| 解析音域を全音域(C1〜B7)にする | VocalShifter LE | pYIN の探索範囲を C1〜B7(約 33〜3951Hz)にする。自動 |
| 「V: 単音ボーカル用」を選ぶ | VocalShifter LE | 不要(声専用の解析) |
| Ctrl+A → 平均化(黄色い線がまっすぐになる) | VocalShifter LE | **平坦化スライダー**(既定 100%)。基準ピッチは重み付き中央値(v1.2 3章)。線の色の約束も踏襲する(元は橙の破線、整えたあとは黄の実線) |
| 自動補正、スケール C/Am | VocalShifter LE | **目標の音名を選ぶ**(既定は基準ピッチに最も近い半音)。スケールの指定は補助(スケール外の音を候補から外す)。書き出す WAV は目標の音名ぴったりの高さになる(A4 = 440Hz) |
| TIME: 母音の始まりに制御点を打ち、右端の赤い線を引いて伸ばす。目安は半小節。子音は伸ばさない | VocalShifter LE | **シンセ化マーカー**(頭部 = 子音、持続区間 = 母音)を自動で提案し、ドラッグで直せる。**長さは拍数(既定 2拍 = 半小節)か秒**で指定。伸ばし方は周期プール(既定)/ループ/伸ばさない |
| Wave ファイル出力 | VocalShifter LE | **書き出し**(5章) |
| RS5K に割り当てる | REAPER | 利用者の DAW で行う。ファイル名に音名を入れ、SFZ も出せるので基準音合わせが不要になる |
| 単音化した素材を Vital の OSC に入れ、PitchSplice を選び、LFO/エンベロープで再生位置を動かす | Vital | 単音 WAV をそのまま使える。加えて **Vital 用ウェーブテーブル**(1周期 2048 サンプル × 複数フレーム)を書き出せば、PitchSplice を経ずに読み込める(論点 D) |

## 3. 基本フロー

```
① 素材を開く(ファイル / 共有シートから / ドロップ)
      └ 自動解析: ピッチカーブ・ピッチマーク・基準ピッチ・立ち上がり・シンセ化マーカーの提案
② 切り出す      範囲ハンドルで鳴らす範囲を決める
③ 整える        目標の音名、平坦化、揺らぎ、フォルマント、伸ばす長さ(拍数 / 秒)
      └ 画面の鍵盤や PC のキーでいつでも試し弾きできる(できあがる音そのもの)
④ 書き出す      渡す先を選ぶ → ファイルを保存 / 共有シートで DAW に渡す
```

- **完了の目安: 素材を開いてから1分以内に、DAW に渡せる WAV が手元にある。**
- ③ で聞こえる音と、④ で書き出される音は**同じエンジンで作る**(聞いたとおりのものが出る)。
- 長い素材から複数の区間を切り出して、まとめて書き出せる(Phase 2。REAPER で S キーを何度も押していた作業に相当)。

## 4. 変換の仕様

[v1.2](design-v1.2.md) の 3章・4章をそのまま使う。v2.0 で変わる点だけ書く。

| 項目 | v2.0 での扱い |
|---|---|
| 解析 | v1.2 3章のとおり(pYIN、cc 方式のピッチマーク、基準ピッチの重み付き中央値、立ち上がり、持続区間の候補)。Phase 1 で実装済み |
| 切り出し | 範囲ハンドル。フェードなしが既定。範囲の端はゼロクロスに寄せる(1〜2ms 以内) |
| 目標の音名 | 基準ピッチに最も近い半音を既定にし、ドロップダウンと ±1 半音ボタンで変える。スケール(C/Am など)を選ぶと、スケール外は候補から外れる。**書き出しは目標の音名ぴったりの高さ**にし、ファイル名に音名を入れる(例 `ore_C4.wav`) |
| 平坦化 | v1.2 ★3 と同じ式。**既定は 100%**(v1.2 の既定 0% は、人力用途を含む DAW だったため。v2.0 の主目的はシンセ化なので 100%。プリセット「原型 0%」「人力 30%」は残す) |
| 揺らぎ | v1.2 と同じ(ビブラート、ゆっくりした揺れ、細かい揺れは既定オン)。平坦でも機械的に聞こえないようにする |
| 伸ばし | シンセ化マーカーで頭部(伸ばさない)と持続区間を分ける。**長さは拍数(既定 2拍)か秒**。伸ばし方は周期プール / ループ / 伸ばさない |
| 語尾 | 既定オン(2026-10-23 変更。離すと語尾の区間が鳴る)。オフにすると伸ばした末尾で約 20ms フェード。音名の下の「鳴らす部分」のスイッチで、持続区間(既定オン。オフで頭部から語尾へ直行)と一緒に切り替える。長さは最後まで / 1 拍 / 1 小節 |
| **削除**(VocalShifter の TIME「選択範囲の削除」) | 波形上で範囲を選び「この範囲を削除」。削除区間は再生時に飛ばされ(グレインの重なりがそのままクロスフェードになる)、周期プールからも外れる。何か所でも。「選択範囲だけにする」は範囲ハンドルを選択に合わせるトリミング |
| **速度**(VocalShifter の TIME の制御点に相当) | 頭部・持続区間・語尾それぞれに倍率(×0.25〜4、持続区間は 8 まで)。1.00 が録音のまま。持続区間の倍率はワンショット(伸ばさない)のときだけ効き、ほかの伸ばし方では音の長さが決める。遅くした無声部分はグレインの向きを交互に反転して金属音と誤ピッチを防ぐ |
| **書き出し後レーン** | エディタの最下段に、出力の時間配分(頭部 / 持続区間 / 語尾の長さと倍率)と、ビブラートの波形(かかり始め・速さ・深さ)を描く。「頭は等速、シンセ部は引き延ばし」が目で確認できる。試し再生中は再生位置の線が動く |
| **削除区間の表示**(試用フィードバック 2026-10-23) | 削除した範囲は斜線ではなく **詰めて表示**し(素材が鳴るとおりの時間軸)、継ぎ目に ✂ の点線だけ残す。表示時間 ⇄ 素材時間の変換は `collapsedTime` / `expandedTime`(layout.ts) |
| **拡大・縮小と横スクロール** | Ctrl + ホイール / ピンチで拡大、ホイール / 2 本指で横スクロール、＋ − 全体 「選択 / 範囲に合わせる」ボタン。拡大中は上端に細い位置バー。表示は最短 0.05 秒 |
| **試し再生** | 波形の上に「▶ 元の音」(範囲内を録音のまま、削除区間を 5ms クロスフェードで飛ばして)と「▶ 書き出し後」(書き出されるファイルそのもの)。どちらも頭から再生し、再生位置の線が動く(元の音は波形の上、書き出し後はレーンの上) |
| ビブラート | 深さ・速さ・かかり始めを「音名・平坦化」のパネル内の折りたたみに出す(VocalShifter の VIB に相当)。揺らぎのほかの項目は細かい設定のまま |
| フォルマント | v1.2 と同じ(半音で指定、±1 が目安) |
| 書き出しの処理 | **オフラインで一括して計算する**(リアルタイムの制約がない)。同じ Engine をメインスレッドか Worker で直接回す。OfflineAudioContext には頼らない(Safari の未確認事項を避ける) |

## 5. 書き出し形式(★5)

| 形式 | 中身 | 渡す先 | 優先 |
|---|---|---|---|
| **単音 WAV** | 目標の音名の高さで、指定の長さに伸ばした1本の WAV。16bit、サンプルレートは素材のまま(44.1k / 48k)。ファイル名に音名・拍数・BPM | REAPER(RS5K)、Vital(PitchSplice)、GarageBand の Sampler、Koala、Logic、Cubasis など**すべてのサンプラー** | **Phase 1(MVP)** |
| **ループ WAV** | 持続区間を長めに作り、安定した部分にループ範囲を埋め込む(WAV の `smpl` チャンク)。クロスフェード付き | ループ点を読むサンプラー(Logic / Quick Sampler、RS5K ほか) | Phase 2 |
| **マルチサンプル音源** | 音域ぶん(例: ±1 オクターブを 3 半音おき)の WAV を PSOLA で個別に作り、**SFZ** と **Decent Sampler(.dspreset)** の定義を付けて zip にする。各 WAV は長さ保持なので「高音で途中で切れる」が起きない | REAPER(sfz: RS5K 代替、sforzando)、**iOS の Decent Sampler(無料・AUv3)**、AudioLayer など | Phase 2 |
| **Vital 用ウェーブテーブル** | 持続区間から 1 周期ずつ取り出し、2048 サンプルに揃えたフレームを並べた WAV(〜256 フレーム) | Vital の OSC へドラッグ・「Import Wavetable」(`clm ` チャンクでフレーム長を伝える)。Serum など同じ慣習の他シンセ | Phase 3(論点 D) |
| 設定の保存・復元 | 切り出し範囲・マーカー・パラメータだけの小さな JSON(素材は含めない)。同じ素材を開き直せば設定が戻る | 自分用 | Phase 2 |
| **キット音源**(ワンショット一括) | 複数ファイルを一度に開くと素材リストになる。各ファイル(の各区間)を 1 鍵ずつ並べた SFZ + .dspreset と WAV の zip。SFZ は `loop_mode=one_shot`、リリースは 1.5 秒以上。調整していない素材は既定でワンショット(録音のまま、その音程)。開いて調整した素材は保存された設定どおりに書き出す。60 秒を超える素材は開いて範囲を選ばない限り飛ばす | REAPER(sforzando)、Decent Sampler(iOS / PC) | Phase 4 ✅ |
| **一括 WAV**(ワンショット一括) | 同じ素材リストから、各ファイルを単音 WAV にして 1 つの zip に | どのサンプラーでも | Phase 4 ✅ |

- zip は依存を増やさないため、圧縮なし(store)の最小実装を自前で書く。
- ファイル名の規則: `<素材名>_<音名>[_<拍数>beat@<BPM>].wav`。出典メモは WAV の `LIST/INFO` に入れる(読める DAW で見える)。

## 6. iOS で使えるようにするための要点(★2)

| 項目 | 方針 |
|---|---|
| 入口 | `<input type="file" accept="audio/*,video/*">`(iOS では「ファイル」「写真」から選べる)。**PWA** にしてホーム画面に置け、共有シートからサイトに素材を渡せるようにする(Web Share Target は iOS 非対応のため、まずはファイル選択が主)。**60 秒を超える素材は、全体の波形から使う範囲(最大 60 秒)を選んでから解析する**(範囲ピッカー。選択範囲の試聴、帯ごとの移動、「別の範囲を選ぶ」で何度でも選び直し。読み込みは 10 分まで) |
| 出口 | **`navigator.share({ files })`** で共有シートを出し、「ファイルに保存」や対応アプリへ直接渡す。使えない環境では `<a download>` にフォールバック。iOS Safari で WAV の共有が通るかは Phase 1 の最初に実機で確かめる(未確認事項) |
| 受け取る DAW の都合 | GarageBand は読み込み時に 44.1kHz / 16bit に変換する(Apple の案内)。48kHz 素材でも問題ないが、GarageBand 向けプリセットでは 44.1kHz に変換して出す選択肢を付ける |
| 音声 | AudioWorklet は HTTPS 必須(本番は Cloudflare で問題なし)。アプリ切り替えで AudioContext が "interrupted" になったら次のタップで再開(v1.2 5章) |
| 処理 | 書き出しはオフライン計算なので、Worker で回し、進捗バーを出す。メモリは 200〜300MB 以内(素材は長くても数分を想定し、長い素材は切り出してから解析する) |
| 画面 | 縦画面の iPhone を基本にする(v1.2 は iPad の横画面が基本だった)。上から「波形と範囲」「ピッチ表示」「つまみ」「鍵盤」「書き出し」の1カラム。iPad と PC では2カラム |

- 最初に開いたときは内蔵の合成ピアノ(C4)が入っていて、本体の画面から始まる(2026-10-27 に声のデモ素材から置き換え。声のデモは保存済みのプロジェクトからも外す)。「音名を選ぶ → 長さを決める → 共有」の3ステップを案内する。

## 13. v3: DAW 化(2026-10-27 決定)

音を作る側(シンセ化・エフェクト・書き出し)が実用水準になり、「曲で試す」で MIDI を鳴らして実用に足ると判断したため、ユーザーの判断で DAW 方向に戻る。1 章「やらないこと」のうち打ち込み・曲の書き出しはこの章で上書きする。

決定事項:
- **ゴール**: アプリ内で曲まで完結(打ち込み・複数トラック・ミックス・曲の WAV 書き出し)。
- **端末**: PC とスマホを同等に扱う(マウス / 指それぞれの操作を作る)。
- **TapMV**: 別ツールのまま。連携は考えない。
- **入れないもの**: GM 音色・プログラムチェンジ、汎用 CC / オートメーションレーン(音量・パン程度に絞る)、拍子の途中変更、楽譜表示、スウィング、MPE、MIDI チャンネルの編集。

段階:
1. **土台と 1 トラックの打ち込み**: 拍単位のデータ(`src/daw/`)、ピアノロール(置く・消す・動かす・長さ・吸着・範囲選択・コピー・複製・移調・取り消し)、ループ範囲つき再生、ブラウザ内への自動保存、「曲で試す」のパートの取り込み。鳴らすのは今の素材。
2. **複数トラック・複数素材**: エンジンを素材ごとに持つ、ミキサー(音量・パン・ミュート・ソロ)、ドラムトラック(キット)。
3. **曲の書き出し** ✅: 曲全体の WAV、トラック別 WAV、マスターエフェクト、.mid(2026-10-27。再生と同じミキサー `src/song/player.ts` と音 `src/song/sounds.ts` を `src/daw/songRender.ts` がオフラインで回す)。
4. **音MAD 向けの仕上げ** ✅: ポルタメント、クオンタイズ、ベロシティ、ステップ入力(2026-10-27)。ノートごとの区間選択は 13.1 の方式 A によりやめた。録音と MIDI キーボードは後回し。
   - **ポルタメント**はトラックの設定(秒)。つながった・重なった音符だけを滑らせ、トラックは単音になる。伸ばせる区間は同じ声のまま高さだけ動かし(レガート)、1 回鳴らしきる区間は頭から鳴らし直しつつ前の高さから滑らせる(`Engine.setGlide`)。ぴったりつながった音符は再生用に 2 ms 重ねて、次の音が前の音を離す前に始まるようにする(`toSeqNotes` の legato)。
   - **語尾を収める**(トラックの設定、2026-10-27)。オフ(既定)ではノートを離してから語尾が鳴り、ノートの後ろにはみ出す。オンでは再生がノートの長さを音源に渡し、語尾の長さぶん早く語尾へ入って、ノートの終わりで鳴り終わる。頭部は削らない(頭部の途中から語尾へ飛ぶと無理やりつないだ音になるため)。頭部のあとに残る時間に語尾が入らなければ最大 2 倍まで速く読み、それでも余る分は長めのフェードで閉じる。頭部だけでノートが埋まるときは語尾を鳴らさず、頭部をノートの終わりへフェードさせる。鍵盤の試し弾きは長さを知らないので常にオフの動き。
   - **ベロシティ**はピアノロール下の「強弱」欄で、棒をなぞって変える(選択があれば選んだ音符だけ)。
   - **クオンタイズ**は選んだ音符(なければ全部)の始まりと終わりを吸着の線へ。
   - **ステップ入力**は画面の鍵盤・PC キーボードで弾いた音を再生位置に入れ、吸着の幅だけ進む。同時に押せば和音。休符と「1 つ戻す」。ドラムトラックでは使わない。

### 13.1 第 2 段階の決定(2026-10-27)

- **サンプリング側と曲側に分ける。** サンプリング側 = 素材(音声・ピッチ解析・判定の手直し)と、その中の区間(範囲のマーカー・平坦化・ビブラート・伸ばし方・音量の形・音名)。曲側 = トラック(ノート・エフェクト・音量・パン・ミュート・ソロ)とマスターのエフェクト。
- **トラック = 区間 1 つ(方式 A)。** 「あ」と「い」を切り替えたいときはトラックを分ける。ノートごとの区間選択はしない(利用者が扱えない複雑さを避ける)。
- **エフェクトは区間からトラックへ移す。** 単音の書き出し(サンプリング側の成果物)はエフェクトなしの素の音になる。
- **プロジェクトの形を作り直す。** 複数の素材を同時に持つ。旧形式(素材ごとの設定・1 トラックの打ち込み)との互換は取らない。
- **iOS の負荷:** 同時発音数をトラック単位と全体で制限する。メモリは読み込める素材の合計時間で制限する。
- **ドラム:** ワンショットを設定確定時に 1 回だけ作っておき、曲中では録音を再生するだけにして軽くする。

段階 2 の作業順: (a) 音声スレッドを複数トラックのミキサーにする ✅ → (b) プロジェクトの形と保存 ✅ → (c) 画面(素材の一覧 ✅、トラック一覧とミキサー ✅、エフェクトのトラックへの移動 ✅、マスター ✅)→ (d) iOS の制限 ✅(1 トラック 8 音まで、素材の合計 240 秒まで)→ (e) ドラムトラック ✅(割り当てた区間の数だけ行ができる。各行の音は区間の設定から 1 回だけワンショットとして作り、曲中は再生するだけ)。
